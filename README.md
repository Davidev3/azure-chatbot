# 🤖 Assistente Virtual com Azure Bot Service

Bot conversacional desenvolvido com **Azure Bot Service** e **Azure AI Services** — interação em linguagem natural, navegação guiada e processamento automatizado de pedidos.

---

## Funcionalidades

- 💬 Conversação em linguagem natural via Azure AI
- 🗺️ Menus interativos de navegação
- ⚡ Processamento automatizado de intenções do usuário
- 🔗 Integração com Azure Cognitive Services

---

## Tecnologias

| Recurso | Uso |
|---|---|
| Azure Bot Service | Orquestração do bot e canais de comunicação |
| Azure AI Services | Processamento de linguagem natural (NLU) |
| Bot Framework Composer | Fluxo de diálogo e gerenciamento de estado |
| Azure Portal | Deploy e configuração completa |

---

## Arquitetura

```
Usuário → Azure Bot Service → Azure AI Services (NLU) → Resposta
```

Toda a lógica de diálogo, integração de IA e publicação foram feitas via portal Azure — sem backend customizado exposto.
